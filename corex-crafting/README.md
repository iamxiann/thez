# corex-crafting

> Recipe-driven crafting with categories, workbenches, and blueprints.

Part of the [COREX Framework](https://github.com/ABUGIZA/COREX-Framework).

## Install

Drop the `corex-crafting` folder into:
```
server-file/resources/[corex]/corex-crafting/
```

Make sure it loads after `corex-core`:
```cfg
ensure corex-core
ensure corex-crafting
```

## Update

Download the latest release ZIP from the **Releases** tab and replace the folder.
