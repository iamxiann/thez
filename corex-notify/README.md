# corex-notify

> Unified notification system used across all COREX resources.

Part of the [COREX Framework](https://github.com/ABUGIZA/COREX-Framework).

## Install

Drop the `corex-notify` folder into:
```
server-file/resources/[corex]/corex-notify/
```

Make sure it loads after `corex-core`:
```cfg
ensure corex-core
ensure corex-notify
```

## Update

Download the latest release ZIP from the **Releases** tab and replace the folder.
